# Signal Room · Morse listening practice

An offline-first Morse code listening practice studio.

- Accurate International Morse timing from 1–50 WPM, defaulting to 3 WPM
- Web Audio API tone generation with pause, resume, replay, loop, frequency, volume, and Farnsworth timing
- Letters, words, sentences, paragraphs, numbers/punctuation, custom text, and weak-letter practice
- Character-level answer checking and feedback
- Persistent progress, history, goals, adaptive practice, and light theme
- Installable PWA with local service-worker caching

Run locally with: python3 -m http.server 4173
